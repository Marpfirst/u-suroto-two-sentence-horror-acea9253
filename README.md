A two-sentence horror story, written as a deterministic Node 22 program (stdlib only) that writes the story to `/output/entry.txt`.

The story: a grieving husband clings to the paramedics' reassurance that his wife died instantly and never felt a thing — until her phone finally syncs and her last voice memo proves otherwise.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
